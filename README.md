# Z4D3S - Blog de Ciberseguridad Red Team

![Z4D3S](https://img.shields.io/badge/Z4D3S-Red%20Team-red)
![Astro](https://img.shields.io/badge/Astro-5.x-ff5f03)
![Tailwind](https://img.shields.io/badge/Tailwind-3.x-0ea5e9)

Blog tcnico de ciberseguridad especializado en **Red Team**: pentesting, explotacin, red teaming y seguridad ofensiva. Enfoque 100% educativo y ofensivo.

## Caractersticas

- **Multiidioma**: Espaol, Inglés, Portugués
- **MDX**: Posts con código resaltado e imágenes
- **SEO**: Sitemap, meta tags, Schema.org
- **RSS**: Feed RSS automático
- **Búsqueda**: Buscador integrado
- **Tags y Categorías**: Organización de contenido
- **Dark/Light Mode**: Tema adaptativo
- **Diseño Cyber**: Estética minimalista dark

## Quick Start

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Aviso Legal

El contenido de este blog es **estrictamente educativo**. Los laboratorios ofensivos están diseñados para aprender a atacar sistemas en entornos controlados y autorizados, nunca para dañar sistemas sin permiso.

> "La ciberseguridad ofensiva encuentra las debilidades antes que el adversario."
